# Product Specification

## Product

Business Intelligence + AI Platform

## Target Users

Small and medium-sized businesses.

## Main Problem

Businesses often have data distributed across different systems, making it difficult to understand performance and make data-driven decisions.

## Main Goal

Create a replicable platform that centralizes business data, performs analytics, connects to external APIs, and uses AI to generate useful business insights.

## Core Entities

- Company
- Customer
- Product
- Order
- Transaction

## Initial Capabilities

- Store company data
- Store customers
- Store products
- Store sales
- Calculate business KPIs
- Query data using SQL
- Connect to external APIs
- Generate AI-powered insights
